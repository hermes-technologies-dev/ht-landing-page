# Hermes Technologies — Landing Page

Landing page institucional da **HT — Hermes Technologies**, desenvolvida em **Next.js**, com foco em apresentar a empresa, seus serviços, posicionamento e formas de contato.

> **Ideias que ganham forma.**

A HT atua na criação e desenvolvimento de soluções, combinando **tecnologia, criatividade e execução** para transformar ideias e problemas em soluções reais.

---

## 🚀 Sobre o projeto

Esta aplicação é a landing page oficial da Hermes Technologies.

O projeto foi desenvolvido com uma abordagem moderna, responsiva e orientada à performance, utilizando o ecossistema React/Next.js.

A página tem como objetivos:

* Apresentar a Hermes Technologies;
* Comunicar o posicionamento da empresa;
* Apresentar as principais áreas de atuação;
* Demonstrar a capacidade de criação de soluções personalizadas;
* Facilitar o contato com potenciais clientes e parceiros;
* Estabelecer uma presença institucional para a marca.

A HT não se limita ao desenvolvimento de software. A empresa trabalha com diferentes tipos de soluções, podendo atuar desde produtos digitais até automação, inteligência artificial, prototipagem e produtos físicos.

## 🛠️ Instalação

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta:

```bash
cd <NOME_DO_PROJETO>
```

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:3000
```
